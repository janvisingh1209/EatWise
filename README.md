EatWise 🍽️🤖

EatWise is an AI-driven, disease-specific food recommendation system that helps users make healthier dietary choices based on medical conditions.

## 🧩 Project Structure

## 🚀 Tech Stack

### Frontend
- React.js
- Vite
- CSS

### Backend
- Node.js
- Express.js

### Machine Learning
- Python
- FastAPI
- Decision Tree / XGBoost (planned)

## 🔗 How it works
1. User enters health details via frontend
2. Backend processes and forwards request
3. ML server predicts food recommendations
4. Results displayed on UI
